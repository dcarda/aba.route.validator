# Generated Reports

This document provides an overview of the various reports that are automatically generated by [Maven](https://maven.apache.org) . Each report is briefly described below.

## Overview

| Document | Description |
| --- | --- |
| [Checkstyle](checkstyle.html) | Report on coding style conventions. |
| [Javadoc](apidocs/index.html) | Javadoc API documentation. |
| [JavaNCSS Report](javancss.html) | Code metric analysis. |
| [JDepend](jdepend-report.html) | JDepend traverses Java class file directories and generates design quality metrics for each Java package. JDepend allows you to automatically measure the quality of a design in terms of its extensibility, reusability, and maintainability to manage package dependencies effectively. |
| [Source Xref](xref/index.html) | HTML based, cross-reference version of Java source code. |
| [Third Parties](third-party-report.html) | Provides details of third parties of the project. |
| [CPD](cpd.html) | Duplicate code detection. |
| [PMD](pmd.html) | Verification of coding rules. |
| [SpotBugs](spotbugs.html) | Generates a source code report with the SpotBugs Library. |
| [Surefire](surefire.html) | Report on the test results of the project. |
| [Tag List](taglist.html) | Report on various tags found in the code. |
| [Dependency Updates Report](dependency-updates-report.html) | Provides details of the dependencies which have updated versions available. |
| [Plugin Updates Report](plugin-updates-report.html) | Provides details of the plugins used by this project which have newer versions available. |
| [Property Updates Report](property-updates-report.html) | Provides details of properties which control versions of dependencies and/or plugins, and indicates any newer versions which are available. |
| [Change Log](changelog.html) | Generated change log report from SCM. |
| [File Activity](file-activity.html) | Generated file activity report from SCM. |
| [Developer Activity](dev-activity.html) | Generated developer activity report from SCM. |
