Generated Reports

This document provides an overview of the various reports that are automatically generated by Maven[1] . Each report is briefly described below.

Overview

Document Description
Checkstyle[2] Report on coding style conventions.
Javadoc[3] Javadoc API documentation.
JavaNCSS Report[4] Code metric analysis.
JDepend[5] JDepend traverses Java class file directories and generates design quality metrics for each Java package. JDepend allows you to automatically measure the quality of a design in terms of its extensibility, reusability, and maintainability to manage package dependencies effectively.
Source Xref[6] HTML based, cross-reference version of Java source code.
Third Parties[7] Provides details of third parties of the project.
CPD[8] Duplicate code detection.
PMD[9] Verification of coding rules.
SpotBugs[10] Generates a source code report with the SpotBugs Library.
Surefire[11] Report on the test results of the project.
Tag List[12] Report on various tags found in the code.
Dependency Updates Report[13] Provides details of the dependencies which have updated versions available.
Plugin Updates Report[14] Provides details of the plugins used by this project which have newer versions available.
Property Updates Report[15] Provides details of properties which control versions of dependencies and/or plugins, and indicates any newer versions which are available.
Change Log[16] Generated change log report from SCM.
File Activity[17] Generated file activity report from SCM.
Developer Activity[18] Generated developer activity report from SCM.
